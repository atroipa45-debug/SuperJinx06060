# ربات فروش و پنل مدیریت | جینکس | 𝙎𝙪𝙥𝙚𝙧 𝗝𝗶𝗻𝗫

ربات تلگرام فروش کانفیگ همراه با پنل مدیریت تحت وب (پورت 8080). ربات و پنل در یک سرویس اجرا می‌شوند.

## راه‌اندازی روی Railway

1. همه فایل‌های این پوشه (بدون هیچ زیرپوشه‌ای) را در یک مخزن GitHub آپلود کنید و در Railway گزینه **Deploy from GitHub** را بزنید.
2. **خیلی مهم:** در Railway روی سرویس، از بخش **Volumes** یک Volume بسازید و مسیر آن را `/data` قرار دهید. اگر این کار را نکنید، با هر ری‌استارت همه اطلاعات (کاربران، سفارش‌ها، تنظیمات) پاک می‌شود.
3. در بخش **Variables** متغیر `PORT` را برابر `8080` قرار دهید.
4. در بخش **Settings** و **Networking** گزینه **Generate Domain** را بزنید و پورت را `8080` انتخاب کنید.
5. لینک دامنه را باز کنید. راه‌اندازی مرحله‌ای نمایش داده می‌شود: توکن ربات، آیدی عددی ادمین، لینک پنل و رمز ورود.

بعد از راه‌اندازی، داخل ربات برای ادمین‌ها دکمه **پنل مدیریت** نمایش داده می‌شود که همین پنل را داخل تلگرام باز می‌کند و ادمین بدون رمز وارد می‌شود (احراز هویت امن تلگرام).

## متغیرهای اختیاری

| متغیر | توضیح |
|---|---|
| `PORT` | پورت پنل (پیش‌فرض 8080) |
| `DB_PATH` | مسیر دیتابیس (پیش‌فرض `/data/bot.db`) |
| `BRAND_CHANNEL` | لینک کانال سازنده که روی نام جینکس در پنل قرار می‌گیرد |

## پنل‌های پشتیبانی‌شده

- **Marzban** (و فورک‌های سازگار)
- **Marzneshin**
- **3x-ui (Sanaei)** و **X-UI (Alireza)**
- **Hiddify Manager** (API نسخه ۲)
- **API سفارشی**: برای اتصال به هر پنل دیگر
- **انبار کانفیگ دستی**: کانفیگ‌ها را از هر پنلی بسازید و در انبار قرار دهید؛ ربات بعد از هر خرید یکی را تحویل می‌دهد

### قرارداد API سفارشی
ربات به آدرس واردشده درخواست `POST` با هدر `Authorization: Bearer <کلید API>` و بدنه JSON زیر می‌فرستد:

- `{"action":"ping"}`
- `{"action":"create","username":"...","volume_gb":50,"days":30,"users":1}` ← پاسخ: `{"link":"...","meta":{...}}`
- `{"action":"renew","meta":{...},"volume_gb":50,"expire":1735689600,"users":1}`
- `{"action":"usage","meta":{...}}` ← پاسخ: `{"used":0,"total":0,"expire":0}` (حجم به بایت)
- `{"action":"delete","meta":{...}}`

## قابلیت‌ها

- فروش با کارت به کارت (ارسال رسید برای ادمین با دکمه تأیید و رد) و کیف پول
- تحویل خودکار سرویس همراه کد QR، تمدید، نمایش مصرف لحظه‌ای
- اکانت تست، کد تخفیف، سیستم زیرمجموعه‌گیری با پورسانت، نمایندگان فروش با قیمت همکار
- تیکت پشتیبانی دوطرفه (از ربات و پنل)
- طراحی دکمه‌ها از پنل: متن، رنگ (آبی، سبز، قرمز، پیش‌فرض)، ترتیب، عرض و دکمه‌های سفارشی
- ویرایش همه متن‌های ربات با پیش‌نمایش زنده
- پیام همگانی با کنترل سرعت و پیگیری پیشرفت
- عضویت اجباری، تأیید شماره، حالت تعمیرات، ضد اسپم
- هشدار خودکار انقضا، بکاپ خودکار روزانه برای مالک، دانلود بکاپ از پنل
- ادمین‌ها با سطح دسترسی (مدیر کل، تأیید پرداخت، پشتیبانی)

## کارایی

- پردازش هم‌زمان پیام‌ها (هر کاربر صف جداگانه دارد، تا ۴۰۰ درخواست هم‌زمان)
- دیتابیس SQLite در حالت WAL با ایندکس‌های لازم
- یک اتصال HTTP مشترک و ماندگار برای تلگرام و پنل‌ها
- مدیریت خودکار محدودیت سرعت تلگرام (خطای 429)

اجرای محلی: `pip install -r requirements.txt` و سپس `python main.py`
